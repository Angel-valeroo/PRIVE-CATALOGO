# Fuentes y estado de revisión — Base Maestra PRIVÉ

El catálogo operativo PRIVÉ es la fuente de verdad para diseñador, nombre, clave y categoría.

Las fichas del Lote 001 se encuentran en estado `review`. Cuando existe una referencia pública, la ficha conserva su URL y distingue entre sitio oficial y referencia comunitaria. Los registros sin una referencia pública vinculada se marcan con confianza baja hasta su validación.

Las descripciones y orientaciones fueron redactadas para PRIVÉ; no son copias textuales de las fuentes. La tendencia de edad es orientativa y no restrictiva.
