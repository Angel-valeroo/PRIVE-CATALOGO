PRIVÉ — S22 V1.1 — DISEÑO VERTICAL COMPACTO PDF/EXCEL

CAMBIO DE ESTA VERSIÓN
- Ambos PDF pasan de carta horizontal a A4 vertical: márgenes estrechos, cabecera
  más compacta, filas dinámicas con texto legible y pies de página conservados.
- Ambos Excel mantienen toda la información; configuración de impresión A4
  vertical, columnas más compactas, ajuste al ancho y márgenes reducidos.
- Mantiene EXACTAMENTE el orden S22 probado: primero CP, luego DP y UP,
  cada grupo en orden numérico natural. No cambian consultas, permisos, claves,
  cantidades, muestras, notas ni formato de exportación.
- No requiere SQL.

INSTALACIÓN (las funciones Edge no se publican automáticamente con GitHub)
1. Extrae el ZIP PEQUEÑO en la raíz de tu repositorio GitHub, reemplazando 4 index.ts.
2. Comprueba en GitHub Desktop que solo aparecen las cuatro Edge Functions;
   Commit y Push origin.
3. En Supabase > Edge Functions > cada una de las cuatro funciones,
   abre Code, sustituye el contenido del index.ts con el nuevo y pulsa Deploy updates.
4. Descarga un PDF del proveedor de un corte conocido y revisa páginas, legibilidad
   y orden; después prueba el PDF individual y el Excel si lo imprimes.

NOTA: la orientación de IMPRESIÓN de XLSX se establece en las propiedades
SheetJS disponibles; Excel puede requerir confirmar orientación vertical en
Archivo > Imprimir según la versión/visor usado.

Esta entrega tiene verificación local TypeScript y conservación del orden S22.
No se probó contra la base Supabase real.
