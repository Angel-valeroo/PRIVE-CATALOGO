# S14 V1.2 · Reconfirmación de pedidos reabiertos

## Problema corregido
Un pedido podía quedar `reopened`, vencer su corte original y después fallar al volver a confirmar con:
`El corte original ya cerró; no se puede volver a confirmar este pedido`.

## Nueva regla
- Si el corte original sigue abierto, se conserva.
- Si ya cerró, al volver a confirmar el mismo pedido pasa automáticamente al próximo corte activo.
- El pedido no se duplica.
- Se conservan sus líneas, notas y folio.
- Si cambia de corte, se limpian únicamente las marcas logísticas temporales de `delivery_items` de ese pedido para evitar arrastrar estados de entrega del corte anterior.

## Despliegue
Solo requiere ejecutar:
`sql/PRIVE-S14-V1.2-RECONFIRMAR-SIGUIENTE-CORTE.sql`

No requiere Edge Function ni cambios de frontend.
