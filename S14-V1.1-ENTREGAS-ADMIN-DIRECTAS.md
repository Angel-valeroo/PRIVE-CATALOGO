# PRIVÉ · S14 V1.1 · Entregas directas del administrador

## Corrección
S14 V1 marcaba una línea completa como entregada. Si una línea del pedido del administrador tenía cantidad 2 y la nota `SELENE, ANDREA`, marcar a SELENE también marcaba a ANDREA.

## Regla V1.1
- Los pedidos de **distribuidores** se muestran consolidados. Sus notas de cliente no se usan para dividir la entrega del administrador.
- Los pedidos hechos desde **la misma cuenta admin que está usando el Panel** sí pueden dividirse por cliente final.
- Si `quantity = 3` y `customer_note = "ANA, BETO, CARLA"`, aparecen tres entregas independientes de 1 perfume cada una.
- Si la cantidad y el número de nombres no coinciden, la línea no se divide automáticamente para evitar inventar asignaciones.
- Cuando una línea admin se divide y además tiene muestras, las muestras aparecen como una asignación separada para no adivinar a qué cliente corresponden.
- Cada asignación puede marcarse Entregada/Pendiente de forma independiente y se conserva entre sesiones.
- Los pedidos originales y sus notas siguen intactos.
